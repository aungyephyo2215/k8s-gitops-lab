Architecture

How the pieces fit together

Container

Nginx Alpine serving static content with production-hardened security: non-root user, read-only filesystem, dropped capabilities, resource limits.

GitOps Pipeline

Push code to Git. GitHub Actions builds the image. ArgoCD Image Updater detects the change. ArgoCD syncs to the cluster. Zero manual steps.

Security

Pod security context, network policies, RBAC via AppProject, TLS via Let's Encrypt, automated certificate renewal.

Deployment Pipeline

How code reaches production

1
Code Push

Developer pushes changes to GitHub main branch

2
CI Build

GitHub Actions builds Docker image, pushes to GHCR with SHA + latest tags

3
Image Detection

ArgoCD Image Updater detects new tag in container registry

4
Git Update

Image Updater commits new tag to kustomization.yaml in Git

5
GitOps Sync

ArgoCD detects Git change, syncs new manifests to K3s cluster
