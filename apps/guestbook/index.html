Architecture

Container

Nginx Alpine serving static content. Built with a multi-layer security context and resource limits.

GitOps Pipeline

Push code to Git. GitHub Actions builds the image. ArgoCD syncs to the cluster. Zero manual steps.

Security

Non-root container, read-only filesystem, dropped capabilities, TLS via Let's Encrypt.

Deployment Pipeline

1
Code Push

Developer pushes to GitHub main branch

2
CI Build

GitHub Actions builds Docker image, pushes to GHCR

3
Image Update

ArgoCD Image Updater detects new tag in registry

4
GitOps Sync

ArgoCD syncs new manifests to K3s cluster
