# Kubernetes GitOps Lab

A production-style Kubernetes GitOps laboratory built for learning modern DevOps practices.

## 🚀 Technology Stack

- Kubernetes (K3s)
- Argo CD
- Docker
- GitHub Actions
- GitHub Container Registry (GHCR)
- NGINX Ingress
- cert-manager
- Let's Encrypt

## 📂 Repository Structure

```
.
├── applications/
├── apps/
│   └── guestbook/
├── bootstrap/
└── README.md
```
